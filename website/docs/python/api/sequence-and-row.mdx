# Sequence and Row

A `Sequence` is the grid that `aggregate`, `align` and `materialize` bucket by; a `Row` is what reading one row of a series gives you.

## Sequence

A grid of buckets: fixed steps or calendar units in a time zone.

### `Sequence.every`

_static method_

```python
every(step: Duration, *, anchor: Optional[Time] = None) -> Sequence
```

Fixed-length buckets of `step` (`"5m"` or a `timedelta`), starting
at `anchor` (a time; epoch 0 when not given).

### `Sequence.calendar`

_static method_

```python
calendar(
    unit: Literal['day', 'week', 'month', 'quarter', 'year'],
    time_zone: str = 'UTC',
    *,
    week_starts_on: Optional[int] = None,
) -> Sequence
```

Calendar buckets in an IANA zone; a day is 23 or 25 hours when the
clocks change. week\_starts\_on: 1 = Monday … 7 = Sunday.

### `Sequence.buckets`

```python
buckets(begin: Time, end: Time) -> list[tuple[int, int]]
```

Every bucket overlapping [begin, end] as (begin, end) ms pairs.

## Row

One row: row["cpu"] reads a cell (None for a gap).

### `row.index`

_property_

```python
index: int
```

The row's position in its series.

### `row.begin`

_property_

```python
begin: int
```

The key's start (its time, for a time key), epoch milliseconds.

### `row.end`

_property_

```python
end: int
```

The key's end (its time, for a time key), epoch milliseconds.

### `row.key`

_property_

```python
key: Union[int, tuple[int, int], tuple[Union[float, str], int, int]]
```

The key as the lookups take it: a time, `(begin, end)`, or
`(label, begin, end)`.

### `row.__getitem__`

```python
__getitem__(column: str) -> Cell
```

`x[i]` for one row (negative counts from the end), or `x[a:b]` for a new series of those rows; on a row or event, `x["column"]` for one cell (`None` for a gap).

### `row.get`

```python
get(column: str, default: Any = None) -> Cell
```

The cell in `column`, or `default` when there is no such column.

### `row.keys`

```python
keys() -> list[str]
```

The value column names.

### `row.to_dict`

```python
to_dict() -> dict[str, Cell]
```

`{column: cell}` for every value column.
