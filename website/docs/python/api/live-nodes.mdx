# LiveNode, LiveEvent, LiveOutput

A `LiveNode` has everything under [Building and reading nodes](./live-series.mdx#building-and-reading-nodes) as well as what is on this page.

## LiveNode

A node of a LiveSeries. Equal to another handle on the same node.

### `node.value`

```python
value() -> dict[str, Cell]
```

A rolling window's or reduce's values as they stand now.

### `node.snapshot`

```python
snapshot() -> TimeSeries
```

An aggregation's closed buckets and its open one.

### `node.has_open_bucket`

_property_

```python
has_open_bucket: bool
```

Whether an aggregation has a bucket still open.

### `node.keys`

```python
keys() -> list[str]
```

A partitioned node's partition values, in order of arrival.

### `node.partition`

```python
partition(key: str) -> Optional[LiveNode]
```

One partition (a series), by its value; `None` if it has not
appeared.

### `node.partitions`

```python
partitions() -> dict[str, LiveNode]
```

Each partition (a partitioned series), or the chain's last node
on each partition (a partitioned view).

### `node.collect`

```python
collect(
    *,
    name: Optional[str] = None,
    ordering: Optional[Literal['strict', 'drop', 'reorder']] = None,
    grace_window: Optional[Duration] = None,
    max_events: Optional[int] = None,
    max_age: Optional[Duration] = None,
) -> LiveNode
```

One series of everything the partitions take (or their chains
emit), as events arrive; it starts with what they hold now.

### `node.remove`

```python
remove() -> None
```

Remove the node: it stops working, and nodes built on it keep
what they hold but get no more events. Not the root.

## LiveEvent

One event of a live node: event["cpu"] reads a cell (None for a gap).

### `event.key`

_property_

```python
key: Union[int, tuple[int, int], tuple[Union[float, str], int, int]]
```

The key: a time (epoch ms), `(begin, end)` or `(label, begin, end)`.

### `event.begin`

_property_

```python
begin: int
```

The key's start, epoch milliseconds.

### `event.end`

_property_

```python
end: int
```

The key's end (its time, for a time key), epoch milliseconds.

### `event.__getitem__`

```python
__getitem__(column: str) -> Cell
```

`x[i]` for one row (negative counts from the end), or `x[a:b]` for a new series of those rows; on a row or event, `x["column"]` for one cell (`None` for a gap).

### `event.get`

```python
get(column: str, default: Any = None) -> Cell
```

The cell in `column`, or `default` when there is no such column.

### `event.keys`

```python
keys() -> list[str]
```

The value column names, in schema order.

### `event.to_dict`

```python
to_dict() -> dict[str, Cell]
```

`{column: cell}` for the value columns.

### `event.__len__`

```python
__len__() -> int
```

`len(x)`: the number of rows (events, sessions, partitions).

## LiveOutput

Something a push caused at a watched node. kind "event": the node took
an event (an aggregation: closed a bucket); "batch": the series took
these events in one push; "evict": the node dropped these; "bucket": an
aggregation's open bucket as it now stands; "update": a rolling window's
values as they now stand (None from an aggregation); "columns": the rows
the series took in one push, as a TimeSeries in key order (watching a
root for "columns" alone builds no LiveEvent per row).

### `output.node`

_property_

```python
node: LiveNode
```

The watched node that emitted this output.

### `output.kind`

_property_

```python
kind: OutputKind
```

What happened: "event", "batch", "evict", "bucket", "update" or
"columns" (see the class description).

### `output.event`

_property_

```python
event: Optional[LiveEvent]
```

For "event" and "bucket".

### `output.events`

_property_

```python
events: Optional[list[LiveEvent]]
```

For "batch" and "evict".

### `output.values`

_property_

```python
values: Optional[dict[str, Cell]]
```

For "update".

### `output.series`

_property_

```python
series: Optional[TimeSeries]
```

For "columns".
