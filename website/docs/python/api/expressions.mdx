# Expressions

A per-row rule written as data (pond-ts `col('v').gt(0)`), run inside
pond-rs over whole columns: `col("v") > 0`,
`(col("v") / col("w") > 10) & (col("host") == "h3")`. Combine with
`&`, `|` and `~`, not `and` / `or` / `not`. A comparison with a gap is
false; arithmetic with a gap gives a gap; `x / 0` is a gap. The maths
functions (`sqrt`, `sin`, `cos`, `asin`, `atan2`, `pow` / `**`) are
Rust's, which can differ from pond-ts in the last digit.

## Building one

### `pond.col`

```python
col(name: str) -> Expr
```

The value of column `name` in each row.

### `pond.lit`

```python
lit(value: Union[float, int, str, bool]) -> Expr
```

A fixed value: `lit(100) - col("pct")`.

### `pond.when`

```python
when(condition: Expr, then: _Operand, otherwise: _Operand) -> Expr
```

`then` where `condition` is true, else `otherwise` (a gap counts as false).

```python

```

```python

```

Raised to the power `exponent` (also `**`).

### `Expr.is_missing`

```python

```

### `Expr.fill`

```python

```

Gaps replaced by `value` (an `Expr` or a plain value of the same
kind). In `TimeSeries.map` a gap stays a gap; fill in `with_column`.
