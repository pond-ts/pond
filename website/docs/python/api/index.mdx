## Functions

### `pond.parse_time`

```python
parse_time(text: str, time_zone: Optional[str] = None) -> int
```

Text to epoch milliseconds, as pond-ts Time.parse. Text without an
offset is read in time\_zone (UTC when not given).

### `pond.parse_duration`

```python
parse_duration(text: str) -> int
```

Duration text ("5m") to whole milliseconds.

### `pond.studies`

```python
studies() -> list[dict[str, Any]]
```

Every study described: name, method (its Python name), family,
summary, inputs (columns read), params (options with defaults and
ranges), naming, outputs and output\_names.

### `pond.study_info`

```python
study_info(name: str) -> dict[str, Any]
```

One study described, by pond-ts's name or Python's.

## Errors

### `pond.PondError`

```python
class PondError(ValueError)
```

Bad input data, an unknown column, a column of the wrong kind, a bad
duration, reducer or option word. The message names the call and the
column. A value of the wrong type (text where a number is needed) is a
TypeError instead.

## Type names

The signatures on these pages use these names:

```python
Time = Union[int, float, str, _dt.datetime, _dt.date]

```

`Time` is epoch milliseconds, a datetime (no time zone means UTC), a date or text such as `"2026-03-08T12:00:00Z"`. `Duration` is text (`"500ms"`, `"5m"`, `"1h"`, `"1d"`) or a timedelta. `Aggs` maps each output column to its source and reducer: `{"avg": ("cpu", "avg")}`.
