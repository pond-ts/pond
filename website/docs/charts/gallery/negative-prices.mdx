# Negative prices

A quantity that crosses zero needs a chart that takes zero seriously. Bars
above and below a shared baseline do it: the sign is the direction, the
magnitude is the length, and the zero line is a real feature of the plot rather
than the bottom of it.

## The data

**Real measured data**: the DE-LU **day-ahead** auction price, one row per
hour, over the same Easter weekend 2025 as the other two Energy cards. From
[energy-charts.info](https://api.energy-charts.info) (Fraunhofer ISE),
**CC BY 4.0**, upstream Bundesnetzagentur | SMARD.de.

| Column      | Meaning                                                        |
| ----------- | -------------------------------------------------------------- |
| `timeRange` | The auction hour, as a span — `{ start, end }`, not an instant |
| `price`     | EUR/MWh; **negative is normal**, not an error                  |

Negative prices are a real market outcome, not bad data. When must-run
generation exceeds demand, sellers pay to deliver rather than shut down plant
they can't cheaply restart. This weekend is a textbook case: the eight negative
hours are **Saturday 13:00–15:00** and **Sunday 11:00–15:00**, and the Sunday
run sits exactly on top of the
[1 h 45 m when wind and solar out-produced total load](./renewables-vs-demand.mdx).
The weekend's mean was **+72.06** EUR/MWh, so the negative hours are the
exception the chart exists to show.

The key is a **`timeRange`**, not a time. A day-ahead price _is_ a span — it
clears for the hour — and a span-keyed series is also what gives `<BarChart>` a
width to draw. An instant-keyed row would collapse to the theme's `minWidth`.

The time axis renders in **your** browser's timezone; clock times here are
CEST.

## Build it

**1. Key the series by the hour, not the instant.**

```tsx
const schema = [
  { name: 'timeRange', kind: 'timeRange' },
  { name: 'price', kind: 'number' },
] as const;

const prices = new TimeSeries({
  name: 'de-lu-day-ahead',
  schema,
  rows: PRICE_EUR_MWH.map((price, i) => [
    { start: T0 + i * HOUR, end: T0 + (i + 1) * HOUR },
    price,
  ]),
});
```

**2. Draw it. There is no baseline prop to set.** `<BarChart>` always pulls
`0` into the auto-fitted domain and rests its bars on it, so a series that
straddles zero gets the zero line on screen and negative bars drawn _downward_
for free:

```tsx
<Layers>
  <BarChart series={prices} column="price" axis="eur" gap={2} />
</Layers>
```

That is already the finished shape. Everything below is emphasis.

**3. Colour by sign with `binColors`.** It's the per-bar colour channel —
`binColors[i]` fills bar `i` (the stacked chart's `colors` is per-_group_
instead). Derive it from the series' own data:

```tsx
const price = prices.column('price');
const binColors = Array.from({ length: prices.length }, (_, i) =>
  (price.at(i) ?? 0) < 0 ? negative : positive,
);
```

The two colours come off the **live theme**, not out of a literal, so they flip
with the site's dark mode:

```tsx
const positive = theme.bar.default.fill;
const negative = theme.candle.default.falling.body;
```

Reaching into the candle role is deliberate. The palette keeps one
red/green pair as its "conventional exception" for signed quantities, and a
price below zero is exactly that. There is no dedicated diverging **bar** role
yet — if you find yourself wanting one, that's a theme role to add, not a hex
literal to inline.

## Options to try

| Option                | What it does                                 | Reach for it when                                                     |
| --------------------- | -------------------------------------------- | --------------------------------------------------------------------- |
| `binColors`           | Per-bar fill, aligned to the bars in order   | The sign, a threshold breach, or a zone matters more than the series  |
| `gap`                 | Pixels between adjacent bars                 | Dense hourly data; drop it to `0` and the bars read as a column block |
| `<YAxis min>` / `max` | Pins the domain instead of auto-fitting      | Comparing two periods that must share a scale                         |
| `id` + `onSelect`     | Makes bars clickable, reporting `(id, key)`  | Drilling from an hour into what set it                                |
| `decimate`            | Envelope-draws bars denser than ~1 per pixel | A year of hourly prices; note `binColors` turns it off                |

An explicit `<YAxis min>` **above** zero is the one thing to avoid here: the
bars then rest on the axis floor rather than the zero line, and a negative
price would simply be off-screen.
