# pond-ts (core)

The core package — TypeScript-first time-series primitives, and the
foundation the rest of pond builds on. Batch transforms (`filter`,
`aggregate`, `rolling`, `smooth`, `reduce`), array-column support, JSON
round-trip, and the live-series / live-view model for streaming-style
updates.

:::tip[Also in Rust]
The core comes in Rust too: [pond-rs](/docs/pond-rs/) has the
same batch and live operations and gives the same answers, bit for bit.
[Coming from pond-ts](/docs/pond-rs/coming-from-pond-ts) maps each
TypeScript call to its Rust name.
:::
