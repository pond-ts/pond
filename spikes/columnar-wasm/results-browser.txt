  NOTE — the guarded `sum` is the single biggest cross-engine divergence
  in the whole spike. Node's V8 12.4 runs the guarded path at 0.969 ms,
  indistinguishable from the unguarded 0.972 ms: it makes the
  `Number.isFinite` check free. Chromium 148's V8 runs the same JS at
  3.737 ms — 3.9× the unguarded path. Same source, same machine, same
  data; the WASM kernel is unchanged at ~1.59 ms in both.
  So the port measures 0.61× on Node and 2.35× in Chrome purely because
  the *baseline* moved.
