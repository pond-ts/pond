  derive      = `Sequence.bounded().intervals()` — B `Interval` objects. Paid by
                every implementation; a port cannot remove it without also owning
                the interval key column.
  rows→series = materialising the already-computed answer as rows and letting
                `new TimeSeries` re-columnarise them. Also paid by every
                implementation, because `aggregate` output is interval-keyed and
                pond-ts has no columnar door for interval keys. This is the
                remaining bottleneck once the kernel is fast — and removing it is
                a TypeScript change, not a Rust one.
  ingest      = putting key + value columns into linear memory. Zero only if the
                substrate owns storage end to end; the last column charges it per
                call, i.e. the drop-in-accelerator case.
