  total    = measured, C=4.  kernel = share that scales per column (fitted).
  algo x   = pond-ts per-column cost / the same work as a tight JS typed-array
             loop. Available today, no Rust. n/a where pond-ts already IS that
             loop (reduce / bin / gather have nothing to rewrite).
  lang x   = that JS loop / the Rust kernel. What the port itself adds.
  JS-only  = whole-operation ceiling from the JS rewrite alone.
  +RUST    = whole-operation ceiling with the Rust kernel. BOTH are upper
             bounds: columns already resident, zero boundary, zero ingest,
             whole per-column term replaced, and the Rust shape-kernel is a
             floor for ops that do more per column than it does.
  ~        = soft fit (negative intercept or R2 < 0.9); the split for that row
             does not separate cleanly, read it as indicative only.
