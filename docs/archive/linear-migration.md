Pond, one project per package) on 2026-11-24. The issue title starts with
the old tag; the description holds the PLAN.md entry plus the task's
write-up from its breakout plan (sections over
20 KB, mostly shipped history, are linked rather than copied). Source links in
each issue are pinned to the pre-migration commit
[`ba9a361042`](https://github.com/pond-ts/pond/tree/ba9a36104212cbb51561f03c9e5a769b96b261bb).

Tasks already shipped or archived before the migration are not here: see
[done-tickets.md](done-tickets.md), the frozen breakout plans in
[docs/plans/](../plans/), and [CHANGELOG.md](../../CHANGELOG.md).
