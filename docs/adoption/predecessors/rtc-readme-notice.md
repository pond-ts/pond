> `ChartContainer` / `ChartRow` / layers / `YAxis` composition on a canvas
> data plane, reading a [pond-ts](https://github.com/pond-ts/pond) series
> directly, with live-streaming charts, selection, annotations and more chart
> types. Not an ESnet project.
