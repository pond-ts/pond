> **Looking for a maintained successor?** Pond.js has not had a release since
> 0.9.0 (2019). Its original author's TypeScript rewrite is
> **[pond-ts](https://github.com/pond-ts/pond)** (`npm install pond-ts`,
> docs at [pond-ts.org](https://pond-ts.org)): the same typed time-series
> ideas plus streaming, partitioning and canvas React charts
> (`@pond-ts/charts`, the successor to react-timeseries-charts). A Pond.js →
> pond-ts concept table is
> [here](https://pond-ts.org/docs/pond-ts/mental-model#coming-from-pondjs).
> pond-ts is not an ESnet project.
